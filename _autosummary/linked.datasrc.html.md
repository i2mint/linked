# linked.datasrc

Utils to generate graph data from properties and mini-languages.

### Modules

| [`adjacency`](linked.datasrc.adjacency.html.md#module-linked.datasrc.adjacency)             | Adjacency matrix and adjacency list graph representations.    |
|--------------------------------------------------------------------------------------------------------|---------------------------------------------------------------|
| [`dataframes`](linked.datasrc.dataframes.html.md#module-linked.datasrc.dataframes)           | Pandas DataFrame graph representations and conversions.       |
| [`edgelist`](linked.datasrc.edgelist.html.md#module-linked.datasrc.edgelist)               | Edge list graph representations and conversions.              |
| [`minidot`](linked.datasrc.minidot.html.md#module-linked.datasrc.minidot)                 | mini-dot: A very simple mini-language resembling graphviz dot |
| [`networkx_graphs`](linked.datasrc.networkx_graphs.html.md#module-linked.datasrc.networkx_graphs) | NetworkX graph representations and conversions.               |
| [`vectors`](linked.datasrc.vectors.html.md#module-linked.datasrc.vectors)                 | Graph construction from high-dimensional vector data.         |
